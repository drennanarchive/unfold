Live check: simultaneous claims

The automated tests run on an in-browser Postgres, which handles one request at a time. This page checks the real thing: it sends 8 claims for the same gift at the same instant to your Supabase project (from 8 made-up browsers) and confirms exactly one wins. It then releases that claim straight away.

It uses the first available gift it finds, so that gift shows as "Claimed" for a second or so. Best run before you share the link, or while the sample gifts are still in.
